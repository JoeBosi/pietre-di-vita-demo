# Pietre di Vita (olive oil traceability demo)

![Frantoio Pietre di Vita · Pietre di Vita Olive Mill](frontend/public/og.jpg)

Un concept a titolo didattico: un frantoio toscano inventato le cui bottiglie sono tracciate in quattro fasi firmate e verificabili da un QR. Solo testnet Polygon Amoy, nessun valore reale, tutti i dati sono inventati.

- **Demo online:** https://tracciabilita-olio.blockchain.giuseppebosi.com
- **Tutorial (IT/EN):** https://tracciabilita-olio.blockchain.giuseppebosi.com/tutorial/
- **Prova subito:** [notebook Python in Colab](https://colab.research.google.com/github/JoeBosi/pietre-di-vita-demo/blob/main/notebooks/pietre_di_vita_verifica_it.ipynb) (cartella `notebooks/`) e contratti dei capitoli in `starter/contracts`.
